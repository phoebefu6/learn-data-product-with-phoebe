# Learn Data Product with Phoebe

A guided tour of **29 real data products** - from cloud infrastructure to agentic AI - organized on a **four-tier maturity ladder** and told through one running case: **Kasa**, a fictional Southeast Asian omnichannel retailer with an embedded payments wallet, growing from emailed spreadsheets to a single governed platform.

This is a **capability catalog**, not a build-it-yourself bootcamp. Every product gets the same card - what it is, a Kasa example, the business value, and when to reach for it - so a leader can commission it and a builder can place it.

## The ladder

| Tier | Job | Session |
|------|-----|---------|
| Infrastructure | store + serve | Session 2 |
| Data Analytics | measure + explain | Session 3 |
| Data Science | predict + personalize | Session 4 |
| Gen AI | govern + amplify | Session 5 |

## Sessions

1. **The data product maturity ladder** - what a data product is, the four tiers, why you climb, meet Kasa
2. **Infrastructure** (7 products) - cloud infra, APM, schema design, data dictionary, data dump, data lake, data warehouse
3. **Data Analytics** (11 products) - validation, smart reporting, dashboarding, executive scorecard, self-serve BI, metric development, KPI system design, thematic analysis, biz performance monitoring, insights sharing, dictionary scorecard
4. **Data Science** (5 products) - data literacy, customer segmentation, sales forecasting, machine learning (fraud detection flagship), data product
5. **Gen AI** (6 products) - data governance, data quality scorecard, AI literacy, AI use-case discovery, workflow automation, agentic AI
6. **Composing the platform** (capstone) - the reference architecture, sequencing (crawl / walk / run), ROI per tier
